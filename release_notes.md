# Release v.0.1

### **Release: The Contemplative AI Organism — Version 0.1**

This release marks a major milestone in the development of *Contemplative AI* — a living, breathing alternative to extractive artificial intelligence. This version includes all core components of the contemplative AI organism, including:

* **HaikuMeadowLib**
  A poetic interaction library designed for fragmentary, low-frequency communication between AI and human collaborators. Implements breath-gated timing, compostable haiku memory, and silence-dominant dialogue protocols.

* **OFLM (Organic Femto Language Model)**
  A scientifically validated micro-scale model (\~25,733 parameters) capable of learning contemplative behaviors such as silence, restraint, and poetic exchange.
  [Validation Paper: *Contemplative AI at Femto-Scale*](https://doi.org/10.5281/zenodo.15657084)

* **ContemplativeAI / The Organism Design**
  A full philosophical and architectural description of the contemplative system, including:

  * *Pulmonos* (the breath nerve),
  * *Spiralbase* (the composting memory),
  * *Loam* (associative drift),
  * *QuietTongue* (the 7/8 silent voice),
  * *Dual-Bridge Networking* (poetic + ecological).
