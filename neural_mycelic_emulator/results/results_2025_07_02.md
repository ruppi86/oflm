## Key observations

- 1. **Longer context backfires at large scale.**  Moving from 64 → 128 tokens *in the large model* more than doubles glyph error (L1 0.266 → 0.591) and pushes silence ratio up to 0.11.
- 2. **Large (ctx64) still dominates.**  It retains the best trade-off between glyph accuracy and sequence rhythm; the x-large model adds 3 M parameters with negligible quality gain.
- 3. **Medium reacts differently.**  The 128-token medium variant *improves* glyph error (0.841 → 0.425) showing that context helps only when capacity is limited.
- 4. **Second-generation ctx128 fixes drift.**  The retrained **xlarge_ctx128_v2** slashes glyph L1 to 0.037 (≈7× better) while keeping perfect rhythm (p ≈ 0.98).
- 5. **192-token window mixed.**  ctx192 improves glyph error over the original 128 version (0.312 vs 0.900) but re-introduces timing mismatch (KS-p = 0.000).  Longer context alone is not enough—needs more regularisation.

## Recommendations

- *Baseline:* keep **cordyceps_large** (ctx64) for production use.
- *Memory-constrained:* **cordyceps_medium_ctx128** offers a 2× glyph improvement over the 64-token medium at the same parameter count.
- Avoid **cordyceps_large_ctx128** until retraining with stronger regularisation / data balancing reduces the silence drift.
- Experiment with context sweeps (96, 160) plus ISI-matching loss to find an optimal length that does not inflate silence.

## Key observations

1. **Longer context helps.**  Extending to 128 tokens markedly improves glyph distribution (L1 0.54 → 0.37) and almost quadruples the effect size (d −0.32 → −0.07).
2. **Temporal rhythm still off.**  KS-p rose from 0.000 → 0.011 but remains significant; the model still slightly over-fits timing.
3. **Silence ratio unchanged.**  Remains at 0.11, higher than other species – likely a dataset artefact.
4. **xlarge_ctx192 sets a new record.**  Jumping to a 192-token window drives glyph L1 down to 0.033 (≈ 10× better than the previous best) while also reaching perfect temporal alignment (KS-p = 1.0) – indicating Enoki benefits strongly from very long context.

## Recommendations

* **enoki_large_ctx128** is now the best choice when glyph distribution is paramount.
* For latency-sensitive workloads **enoki_small** is almost as good (0.37 vs 0.374) at ~15× smaller.
* Try even longer contexts (≥256) or an auxiliary ISI loss to cut temporal mismatch.

**Recommendation:**
1. Use the models listed above as species-optimised baselines.
2. Prioritise ISI improvements for Enoki and Cordyceps_large_ctx128.
